# Documentation Architecture

## Purpose

This document defines the documentation architecture of Malāk.

Its purpose is to establish where each type of project knowledge belongs, how documents are classified, how they relate to each other, and how the documentation system evolves without duplication or ambiguity.

---

# Scope

This document applies to all documentation stored under `docs/`.

It governs the structure, responsibility and classification of:

- Architecture documentation
- Governance documentation
- Development documentation
- Operational documentation
- Project documentation
- Architecture Knowledge System documentation
