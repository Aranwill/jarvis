# Descripción general

## Propósito

Capturar principios esenciales para escribir funciones limpias y mantenibles.

---

## Alcance

Este learning pack resume prácticas generales de ingeniería y complementa los
estándares de código del proyecto.

---

# Contenido

Principios clave:

- las funciones deberían hacer una sola cosa;
- mantener las funciones pequeñas cuando resulte práctico;
- utilizar nombres descriptivos;
- evitar efectos secundarios ocultos;
- minimizar las listas de parámetros;
- devolver resultados explícitos;
- priorizar legibilidad sobre brevedad.

Estos principios deberían orientar las decisiones de implementación, pero no
reemplazan los estándares específicos del proyecto.

---

# Consideraciones de diseño

Los Learning Packs proporcionan material educativo y guía de ingeniería. No
definen reglas obligatorias del proyecto.
