# Overview

## Purpose

Capture essential principles for writing clean and maintainable functions.

---

## Scope

This learning pack summarizes general engineering practices and complements the project's coding standards.

---

# Content

Key principles:

- Functions should do one thing.
- Keep functions small whenever practical.
- Use descriptive names.
- Avoid hidden side effects.
- Minimize parameter lists.
- Return explicit results.
- Prefer readability over brevity.

These principles should guide implementation decisions but do not replace project-specific standards.

---

# Design Considerations

Learning Packs provide educational material and engineering guidance. They do not define mandatory project rules.
